## 2. 개선 방안 (우선순위순)

### P0: AI 글쓰기 모듈 구축 (즉시 필요)

**목표**: Gov24 데이터 → 블로그 글 자동 생성

**구현 방식**:
```
Gov24 API (서비스목적요약 + 지원대상 + 지원내용 + 신청방법)
    ↓
AI Writer (GPT-4o-mini / Claude)
    ↓
마크다운 생성 (프론트매터 + 본문)
    ↓
기존 파이프라인 (transformer → validator → thumbnail → deployer)
```

**AI 프롬프트 설계**:
- 시스템 프롬프트: "당신은 한국인 페르소나를 위한 금융/복지 전문 작가입니다"
- 입력: Gov24 서비스 1건의 전체 필드
- 출력: 2,000~3,000자 블로그 글 (H2 헤딩 5개 + FAQ + CTA)
- 제약: 사실 기반 ( hallucination 방지), 기존 글 톤앤매너 일치

**참고 모델**: 5000 프로젝트 `shared/ai_writer.py`
- 3-tier fallback (기본 → 대체 → 경제 모델)
- 카테고리별 프롬프트 템플릿
- 하드 데이터 주입으로 환각 방지

### P1: 스케줄러 구축

**목표**: 정해진 시간에 자동으로 N건 발행

**구현 요소**:
- `scheduler.py`: launchd 기반 정시 실행
- `dispatcher.py`: blog_id → pipeline 실행
- `publish_ledger`: SQLite 기반 발행 기록 (중복 방지)
- `daily_quota`: 블로그별 일일 발행 상한
- `catchup`: 놓친 스케줄 자동 보충

**참고 모델**: 5000 프로젝트 `scheduler.py`
- `schedule` 라이브러리 사용
- 5분마다 catchup 체크
- 발행 큐 (블로그 간 딜레이 180초)

### P2: 데이터 수집 파이프라인

**목표**: Gov24에서 페르소나별 관련 서비스 자동 수집

```
Gov24 API (전체 10,967건)
    ↓
페르소나 키워드 필터링 (청년/중장년/직장인/신혼/무주택/저소득)
    ↓
카테고리 매핑 (서비스분야 → 블로그 category)
    ↓
SQLite DB 저장 (services 테이블)
    ↓
AI 글쓰기 대상 선택 (미발행 서비스 우선)
```

**필터링 개선**:
- 1차: `지원대상` 키워드 매칭 (현재 방식)
- 2차: `서비스명` 기반 정밀 필터링
- 3차: `소관기관유형` 필터 (시군구 제외, 중앙행정기관/공공기관 우선)

### P3: 카테고리 체계 다각화

**현재**: loan(38%), tax(25%), insurance(20%), general(11%), invest(6%)

**개선안**:

| 기존 | 변경 | Gov24 매핑 |
|------|------|-----------|
| loan | 유지 | 주거·자립 |
| tax | 유지 | (세금 관련 서비스) |
| insurance | 유지 | 보건·의료, 임신·출산, 보호·돌봄 |
| invest | 유지 | (투자 관련 서비스) |
| general | **분리** | |
| → employment | 신규 | 고용·창업 |
| → life | 신규 | 생활안정, 보육·교육, 문화·환경 |

**효과**: general 비중 65% → 30%로 축소, 테마별 콘텐츠 집중 가능

### P4: CTA 자동 삽입

**현재 문제**: 236개 중 179개(75.8%)에 CTA 없음

**해결책**:
- Gov24 `상세조회URL` → "자세히 보기" CTA 자동 삽입
- Gov24 `신청방법` → "신청하기" 버튼 텍스트 생성
- Gov24 `전화문의` → "문의처" 섹션 추가

**삽입 위치**: 본문 하단, FAQ 이전

### P5: 내부 링크 균등 분배

**현재 문제**: 상위 2개 글이 전체 링크의 40% 차지

**해결책**:
- `entity_injector.py` 개선: 카테고리별 균등 분배 로직
- 새 글 발행 시, 같은 카테고리 기존 글 2~3개와 교차 링크
- `blog-match.json` 활용: 페르소나-블로그 매핑 데이터로 관련 글 추천

## 3. 구현 단계

### Phase 1 (1~2주): 프로토타입

1. AI writer 모듈 1개 생성 (`scripts/auto-writer/ai_writer.py`)
2. Gov24 → AI 글쓰기 → .md 생성 스크립트 1개
3. 수동 실행으로 10건 테스트 발행
4. 품질 검증 (기존 글과 비교)

### Phase 2 (2~3주): 자동화

1. 스케줄러 구축 (launchd)
2. publish_ledger 기반 중복 방지
3. daily_quota 관리
4. 썸네일 + R2 업로드 자동화

### Phase 3 (3~4주): 고도화

1. 카테고리 체계 다각화
2. CTA 자동 삽입
3. 내부 링크 균등 분배
4. 모니터링 대시보드
